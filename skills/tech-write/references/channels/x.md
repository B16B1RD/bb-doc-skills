# 投稿先：X の短文

X の投稿の読者は、タイムラインを流し読みしていて、最初の 1〜2 行で止まるかどうかを決める。
読者は投稿を開かずに通り過ぎることも多いので、用件と、読者が得るものを冒頭に置く。
この投稿先の制約は、種別の原則（告知・進捗・質問などの用件は `references/comment.md`、
論文・記事の紹介は `references/source-summary.md`）に重ねて適用する。種別の原則は変えない。

## 長さの決め方

投稿先が X の短文なら、依頼に長さの指定があっても無くても、インテークで次の 3 択を毎回聞く
（質問の最大 3 問の枠内に数える）。依頼文に選択が明記されているときも、確認として同じ質問で示す。

| 選択 | 書き方 | 上限の確かめ方 |
|------|--------|----------------|
| 140 字に収める | 1 投稿で完結させる | `x_length.py` を既定の上限 280 で掛ける |
| スレッドに分ける | 投稿ごとに 1 つの用件を置き、1 投稿目だけで要点が分かるようにする | 各投稿を同じ上限 280 で数える |
| 長文投稿（X Premium の長い投稿。X Articles とは別） | 冒頭の数行がタイムラインに出る前提で、用件を冒頭に置く | 利用者のプランの上限を `--limit` で渡す。上限の値は【要確認：利用者のプランの長文投稿の上限】として利用者に確かめる |

利用者が答えられないときや質問できないときは、140 字に収める形で書き、選ばなかった形があることを納品報告に書く。
X Articles の記事を頼まれたときは、この表ではなく `references/channels/x-article.md` を読む。

## 重み付きの文字数

X は重み付きの文字数で上限を判定する。

- 日本語・中国語・韓国語の文字と全角記号は 1 字を 2 と数える。日本語だけなら 140 字で上限 280 に達する
- 英数字・半角記号・欧文の言語の文字は 1 字を 1 と数える。英語の投稿は 280 字まで書ける
- URL は長さに関係なく 23 と数える。短縮 URL に置き換えても数は変わらない。`example.com` のようにスキームのないドメインも X はリンクにするので 23 と数える。ただし `example.jp` や `readme.md` のように国別ドメインを 1 階層で書いたものは、パスが続かなければリンクにならず、普通の文字として数える（スクリプトが X と同じ規則で判定する）
- 絵文字は 1 つを 2 と数える。肌の色や ZWJ で連結した絵文字も 1 つとして数える（スクリプトは近似で数える）
- ハッシュタグとメンションは普通の文字として数える。画像や動画の添付は数えない

英語の投稿にも同じ数え方と上限を当てる。数え直しは目視でせず、納品前にスクリプトで確かめる。

```bash
python3 <このスキルのディレクトリ>/scripts/x_length.py <稿のファイル> [--limit N]
```

出力は投稿ごとの重み付きの文字数と上限との差で、上限を超えた投稿があれば終了コード 1 になる。
超えた投稿は、超過量の分だけ情報の少ない語句から削り、元の材料の主体・数値・条件は削らない。
削っても収まらないときは利用者に長さの選び直しを聞き、聞けなければスレッドに分けた形を提案として添える。
空のファイルや読めないファイルはエラーで止まる。0 字として扱わない。

## スレッド

- 稿のファイルでは、投稿の間を空行 3 つ以上で区切る。空行 2 つまでは同じ投稿の中の改行として数える
- 「1/3」のような番号を付けるときは、番号も文字数に入れて数える
- 1 投稿目で何についてのスレッドかが分かるようにする。2 投稿目以降を読まない読者も多い
- 投稿をまたいで 1 文を切らない

## 記法

- X は Markdown を書式にしない。`**太字**`・`[text](url)`・`#` 見出し・表は記号のまま表示されるので使わない
- 箇条書きは「・」や改行で書く。リンクは URL をそのまま書く
- ハッシュタグは本文の語句と重ならない場合に限り末尾に置く。付けるかどうかは依頼に従い、依頼にないハッシュタグを足さない

## 納品の形

納品物は Markdown でなく、投稿欄に貼ってそのまま送れる平文にする。
スレッドは投稿ごとに区切って示し、各投稿の重み付きの文字数をスクリプトの出力のまま納品報告に添える。
投稿本文は HTML にしない。

## 読者の前提の例

文脈を持たない読み手に渡す「読者の前提」は、次の例から依頼に合うものを選ぶ。

- タイムラインで流し読みしていて、冒頭の 1〜2 行で読むかどうかを決める人
- 書き手をフォローしているが、その分野の専門用語は知らない人
- 引用やリポストで、この投稿だけを前後の文脈なしに見た人
